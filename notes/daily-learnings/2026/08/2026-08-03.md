### Session 2（07:56 — commit `6da4106`）— M3 context 1M + Cron 全分析

#### 1️⃣ Commit 自動更新不耗 context windows
**結論：不會。可以放心用 auto-update。**

**原因分析**：
- `update-session-state.sh` 只更新 3 個檔案（`SESSION_NEXT_PROMPT.md` / `INDEX.md` / 同步 main mirror）
- 這些檔案**不會主動被 LLM 讀**（OpenClaw 預設只載入 `SOUL.md` / `AGENTS.md` / `MEMORY.md`）
- 每次 commit 重新生成只是寫到 disk，**不消耗 LLM context tokens**
- 即使被讀：3 個檔案合計約 3-5KB → 約 1K tokens（佔 1M context 0.1%）

**修正建議**：
- ✅ 用 `post-commit` hook 自動觸發 `update-session-state.sh`（**不再需要 session end 才跑**）
- 因為 1M context 夠大，noise commits 也不影響 context
- 保留「session end SOP 跑一次」的選擇（看 SESSION_END_SOP.md step 6），但不必嚴格遵守

實際上**兩者都可**：current 設計（session end 才更新）也 OK，不會壞。
