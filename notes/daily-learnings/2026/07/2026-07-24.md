## What I Learned
- cwd 變化是 exec 失敗主因 — 每次 exec 開頭加 `cd <path>` 確保一致
- var expansion 漂移是 config 整合的常見陷阱 — `LINE_BOT_TOKEN` vs `LINE_ACCESS_TOKEN` 雙 env var 漂移問題
- CWD 分離執行避免連鎖失敗 — 一個 exec 一個任務，不 `&&` 連接
- 23 標準詞 + 60+ 同義詞變體的 synonyms dictionary 比硬編碼 match 強 — 30/30 tests pass
- KB inverted index + LRU cache (max 100) 是 Worker 優化的關鍵 — 從 O(n) 降到 O(1) lookup
