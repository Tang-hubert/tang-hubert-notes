### 1. OpenClaw Skills Round

#### 1.1 Tavily enable（從 disable → ready）

- **症狀**：`openclaw skills list` 顯示 tavily 為 `disabled`，但 openclaw.json 內 `tavily-search.enabled: true`
- **根因**：openclaw.json 內 `tavily` 跟 `tavily-search` 兩個 entry 並存；系統從 SKILL.md frontmatter `name: tavily` 識別真正的 skill 是 `tavily`，但 `tavily.enabled: false`
- **修法**：把 `tavily.enabled: false` → `true`
- **驗證**：`openclaw skills info tavily` 顯示 `✓ Ready`、`Visible to model: yes`
- **自動 reload**：改完不需重啟 gateway

#### 1.2 Take-the-wheel 結構性問題（最終 user 自行解）

- **症狀**：從 ClawHub 安裝後 `info take-the-wheel` 仍 `not found`，`openclaw skills list` 也找不到，`system prompt` 的 `available_skills` 沒注入
- **嘗試方法**（全部無效）：
  - `openclaw skills install ~/.openclaw/skills/take-the-wheel --force` 從 local
  - `openclaw skills install --global`
  - 從 ClawHub ref 重新裝（download + install 都成功但 list 仍沒）
  - `openclaw.json` 加 `take-the-wheel.enabled: true`
  - `openclaw doctor --deep --yes`（沒報 skills 相關錯誤）
  - `openclaw skills update`、`verify`（verify 通過、update 說 not tracked）
  - `openclaw skills workshop list`（No proposals）
  - `openclaw skills curator`（0 active）
- **參考網路**：
  - [GitHub Issue #4709 (NVIDIA/NemoClaw)](https://github.com/NVIDIA/NemoClaw/issues/4709) — 完全對應症狀，issue 確認 "agent CAN use the skill"
  - [sfailabs guide](https://sfailabs.com/guides/openclaw-skill-not-found) — 推薦 `openclaw doctor --deep --yes` 自動修 80%
- **最終解法（user 自己）**：在 SKILL.md frontmatter 補上 `name: "Take the Wheel"` + `slug: "take-the-wheel"` 等欄位後，`openclaw skills list` 出現了
- **結論**：openclaw runtime 識別 skill 機制**依賴 SKILL.md frontmatter 完整性**（不只是目錄存在）

### 2. Perplexity / Tavily Routing 決策

#### 2.1 雙軌 routing 設計

| Context | 用什麼 | 機制 |
|------|------|------|
| **Cron jobs**（isolated agentTurn, 新聞爬蟲等）| Perplexity（native `web_search`）| 不動，cron 沒 expose tavily |
| **Main session** 平常互動 | Tavily（skill via `exec`）| brtclaw 改用 `node ~/.openclaw/workspace/skills/tavily-search/scripts/search.mjs` |

**結論**：不互斥、兩個並存；cron 維持 native Perplexity，main session 加 Tavily skill

**選擇 Tavily**：API key 已配、$0 新增成本、定位跟 Exa 重疊

#### 2.3 TAVILY env var rename

- **問題**：`.env` 是 `TAVILY_SEARCH_API_KEY`，skill 讀 `TAVILY_API_KEY`（不一致）
- **風險**：不能只改 `.env`，會壞 MCP（openclaw.json 還用 `${TAVILY_SEARCH_API_KEY}`）
- **最終解法（user 自己）**：`.env` 跟 `openclaw.json` 兩處都改成 `TAVILY_API_KEY`
- **驗證**：skill 跑一次回傳 IBM 文件（"verify rename" query）✓
