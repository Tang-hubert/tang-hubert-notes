### Sign G — Check 10 AGENTS.md Drift 修法 (commit `03afb64`)

#### 問題分析

Production runtime AGENTS.md（canonical，LLM 真的讀）vs dev repo AGENTS.md（git tracked）有 drift，Check 10 報 `DRIFT: AGENTS.md ↔ AGENTS.md`

#### 修法（兩個檔）

**1. scripts/sync-canonical.sh**：
- 原本：`{ printf '%s' header; echo; cat dev }` — heredoc 沒 trailing newline，`echo` 加一個，但 printf 又漏一個，body 多 1 行空行
- 修法：`{ printf '%s\n' header; cat dev }` — 確保 header 結尾有 newline（不依賴 heredoc）

**2. scripts/check-quality.sh Check 10**：
- 原本：`tail -n +15` 跳 14 行（基於 14 行 header 假設）
- 修法：`tail -n +14` 跳 13 行（匹配新 header 嚴格 13 content 行）

#### 驗證

```

dev repo md5:           f4542f4ccfcdac2b67764bae29cebc77
✅ MATCH
```

### 🎓 教訓整合 (4 條)

1. **PRODUCTION RUNTIME CANONICAL 標頭是設計意圖，不是 bug** — `printf '%s'` 加 `echo` 是原始作者為了確保 14 行 header（13 content + 1 trailing blank）。我先以為是冗餘 echo 想拿掉，結果因為 heredoc 沒 trailing newline，導致 body 偏移 1 行。最後改用 `printf '%s\n'` 強制確保 newline + Check 10 改 `tail -n +14` 跳 13 行。

2. **Worker KB 前處理省 LLM token** — 19 FAQ bundled 共 5.6KB，客戶查常見問題直接 reply canned，跳 LLM Gateway forward + LLM inference 成本。Worker deploy 29.47 KiB（gzip 8.42 KiB），符合 1MB Worker 限制。

3. **wrangler OAuth deploy 是 ambient 流程** — `wrangler whoami` 確認已登入，deploy 直接上 Cloudflare production。但 Worker repo 本地 git push 失敗（無 remote config），wrangler deploy 跟 git push 是兩條獨立路徑。

4. **L2 §I-5 7 天 buffer .bak cleanup 重要但容易被忽略** — 7/15 之前累積的 9 個 .bak（Round 1+2 之後的 sync-canonical.sh 每次跑都 .bak），今天清理 5 個（2 sqlite-import 6/10 + 3 7/15），剩 15 個待 7-day buffer 到期再清。
