# 2026-06-16

## What I Learned
- OpenClaw exec 環境限制：每次 exec 結束 kill child process，background 進程（order-listener/dashboard-server/tunnel）必須在 Hubert SSH session 內啟動
- 監聽式 CSV 寫入不可靠：放棄 order-listener 改用 LINE quick reply + postback + HTTP API
- LLM 生成的格式要簡單純文字（不用 JSON 括號），用 `===訂單確認===...===END===` action blocks 仍會出錯
- 實測失敗是常態：Worker 部署成功不代表 production 行為正確

**Hubert 兩個問題：**

2. Cloudflare Tunnel 顯示「找不到此頁面」

**order-listener 分析：**
- 原理：每 3 秒輪詢 SESSIONS_DIR 掃描新 session，解析 action blocks，呼叫 writeOrder
- 資源：< 0.1% CPU、~30-50 MB RAM、每分鐘 20 次掃描
- 更好的做法：chokidar 事件驅動

**Cloudflare Tunnel 404 真正原因：**
- **不是程式碼問題，是 OpenClaw exec 環境限制**
- 每次 exec 結束都 kill 子進程
- setsid + nohup + disown + double-fork 都無法完全分離
- 解決方案：Hubert 在 SSH session 內執行 `manage-tunnel.sh`

### 環境限制總結

1. **OpenClaw exec 環境無法保持 background 進程**：每次 exec 結束都 kill child
   - 解決：所有 background 服務（api-server、dashboard-server、order-listener 等）必須在 Hubert SSH session 內啟動
2. **Cloudflare Tunnel Quick Tunnel URL 不固定**：每次啟動 URL 變，需要 Named Tunnel（要 OAuth login）才能固定
3. **真實 LINE 測試只能由 Hubert 做**：OpenClaw exec 不能用真實 LINE webhook 測試
